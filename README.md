# SCD Assignment 1: Java OOP & AI Code Critique

This repository contains the completed tasks for **SCD Assignment 1**, covering fundamental Object-Oriented Programming (OOP) concepts in Java and evaluating AI-generated code quality.

---

## 📌 Project Structure

The project is structured into four distinct tasks:

- **Task 1: Encapsulation (`BankSystem`)**
  - Demonstrates data hiding and encapsulation by using private fields, getters, setters, and state validation for financial operations (deposit/withdraw).
- **Task 2: Inheritance & Polymorphism (`Evolving Workforce`)**
  - Features an `Employee` base class with specialized derived classes (`Developer`, `SalesManager`).
  - Utilizes dynamic method dispatch to calculate specific compensation structures at runtime.
- **Task 3: Abstraction (`Design by Contract`)**
  - Defines a `SmartDevice` interface enforced across `SmartLight` and `SmartAC` implementations to maintain loose coupling.
- **Task 4: AI Code Review & Refactoring (`Library System`)**
  - Critiques and refactors AI-generated boilerplate code (`Book` and `Member` classes) to enforce access control, prevent state corruption, and handle duplicate checkout logic safely.
